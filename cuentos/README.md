# Sección: Cuentos Infantiles

En esta carpeta se gestionan los cuentos populares y clásicos adaptados para niños de 6 a 10 años.

## Criterios Específicos:
- Pertenecer al dominio público (Hermanos Grimm, Hans Christian Andersen, Charles Perrault, folclore popular).
- Adaptación respetuosa con estructura clara (Inicio, Nudo, Desenlace).
- Extensión: 200 - 300 palabras.
