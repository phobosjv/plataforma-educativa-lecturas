# Sección: Fábulas Infantiles

En esta carpeta se gestionan las fábulas tradicionales adaptadas para educación primaria.

## Criterios Específicos:
- Relatos de Esopo, Samaniego, Iriarte o La Fontaine libres de derechos.
- Incluir una moraleja integrada o reflexión final comprensible para niños de 6 a 10 años.
- Extensión: 200 - 300 palabras.

## Estructura de entrega:
- Cada fábula en su propia carpeta: `fabulas/<slug>/`.
- Dentro: `<slug>.txt` (ficha CMS) e imágenes `<slug>_mini_800x500.png`, `<slug>_cuerpo_1.png`, `<slug>_cuerpo_2.png`.
